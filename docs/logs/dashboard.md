# 暨南大學｜課程排課系統

一個以純 HTML / CSS / JavaScript 製作的課程排課與學分進度儀表板，用來掌握畢業學分要求、規劃本學期選課，並即時查看各類別修課進度。

## 功能總覽

### 綜合總覽頁（index.html）

- **學分完成情況**
  - 總學分進度條（已修學分 / 128）與百分比
  - 必修 / 選修 / 領域課程進度明細，未達標項目會以紅色警示
  - 右側「總計」卡片：環形圖顯示整體完成百分比
- **本學期課程**
  - 以分頁籤切換四種來源：資工系必選修、體育、全校共同必修、通識
  - 類別下拉篩選與關鍵字搜尋（課名、老師、課號）
  - 分頁瀏覽、一鍵加入 / 退選、衝堂狀態標示
  - 「＋ 手動新增」彈窗：可補登加簽、外系課或資料中沒有的課程（課名、學分、類別、時間、老師、地點）
- **右側欄**
  - 課程分類進度：專業必修、專業選修、校共同必修、通識（人文 / 社會 / 自然 / 特色）、自由學分，各以不同顏色進度條呈現
  - 已選課程精簡清單：加課、退選當下立即更新，固定高度並可內部捲動

### 其他頁面（導覽列連結）

- `timetable.html`：課表
- `settings.html`：系統設定

## 樣式說明（dashboard.css）

### 色彩變數

| 變數 | 用途 |
| --- | --- |
| `--navy` `--blue` `--light-blue` | 主色系（側欄、按鈕、強調） |
| `--line` `--text` `--muted` | 邊框、文字、次要文字 |
| `--green` `--red` `--orange` `--purple` | 狀態與分類色 |

### 版面

- `.layout`：整頁 flex 容器，左為 `.sidebar`（190px），右為 `.main`
- `.columns`：grid 兩欄，左側彈性、右側固定 305px
- `.credit-grid`：學分進度與總計卡片並排

### 類別標籤顏色

| class | 對應類別 | 色系 |
| --- | --- | --- |
| `.status.pur` | 專業選修 | 紫 |
| `.status.hum` | 通識－人文 | 橘 |
| `.status.soc` | 通識－社會 | 紅 |
| `.status.nat` | 通識－自然 | 綠 |
| `.status.spe` | 通識－特色 | 青 |
| `.status.com` | 校共同必修 | 粉紅 |
| `.status.manual` | 手動新增 | 淡橘 |
| `.status.conflict` | 衝堂 | 紅 |
| `.status.none` / `.idle` | 未分類 / 未選 | 灰 |

### 響應式斷點

- **≤ 900px**：主內容改為單欄，學分卡片上下堆疊
- **≤ 620px**：側欄縮為 64px 僅顯示圖示，搜尋欄滿版，個人資料隱藏年級

## 使用方式

1. 將專案放在同一資料夾，確認 `css/`、`js/` 目錄與 HTML 檔案路徑正確。
2. 直接以瀏覽器開啟 `index.html`；若 `app.js` 以 `fetch` 載入課程資料，請改用本機伺服器，例如：

   ```bash
   python -m http.server 8000
   ```

   然後開啟 `http://localhost:8000`。

## 備註

- 畢業學分預設為 **128**。
- 通識規則：總計至少 15 學分，且每個領域至少 3 學分，未達標時會顯示尚差學分提示。
- 頁面語言為繁體中文（`lang="zh-Hant"`），字體優先序為 Noto Sans TC → Microsoft JhengHei → Arial。
