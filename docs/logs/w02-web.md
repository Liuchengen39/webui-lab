### index.html 使用的語意化標籤

| 標籤 | 位置 | 初學者理解 |
|---|---|---|
| `<aside>` | [index.html](index.html#L11) | 主要內容旁邊的輔助內容，例如側邊欄。 |

### 沒有特殊語意的標籤

- `<div>`：通用區塊容器，本身沒有特殊含義。
- `<span>`：行內容器，本身沒有特殊含義。

目前頁面沒有使用 `<nav>`。如果要明確表示側邊欄是網站導覽，可以將導覽按鈕放進 `<nav>` 裡。

### 為什麼要使用語意化標籤？

語意化標籤可以讓瀏覽器、搜尋引擎和螢幕閱讀器理解每個區域的用途。

例如：
- `<main>` 表示主要內容。
- `<aside>` 表示側邊內容。
- `<nav>` 表示導覽。
- `<form>` 表示表單。
- `<footer>`表示頁尾。

即使不看 CSS，也能大致理解 HTML 的結構。

### Project Milestone

#### Problem
我要解決什麼問題？
- 目前市面上的工具要麼只做課表、要麼只做記帳，無法無縫整合
- **課表與校園生活**：快速查詢下一堂課的時間地點，避免遲到
- **個人財務**：手動記帳追蹤日常開支，了解消費習慣與預算控制
- **課程規劃**：根據暨大的畢業門檻架構規劃選課

#### Target Users
誰會使用？
- **主要用戶**：暨大大學生
- **使用場景**：
- 早上查課表、掌握上課時間
- 日常記帳、了解本月消費
- 學期初規劃選課時參考畢業學分要求

#### Core Features
- **Dashboard**：當日課表 + 下堂課提醒 + 本月支出概覽 + 近七日支出趨勢圖
- **Timetable**：週課表視圖 + 課程新增刪除 + 畢業學分追蹤
- **Accounting**：日期分組明細 + 支出/收入圖表 + 數字鍵盤輸入 + 類別管理
- **Settings**：Google 帳號登入 + 資料備份 (CSV/JSON)
- **跨裝置同步**：Google Drive 雲端自動備份 

#### Data
需要哪些資料？
**課程資料**
- 課程名稱、教室、教授、上課時間（星期/節次）、課程標籤顏色
- 暨南大學課程架構（通識、專業必修、專業選修、領域課程等）
**記帳資料**
- 日期、金額、類別（支出：早中晚餐/飲料/宵夜 + 自訂；收入：生活費/打工/獎學金/其他）
- 備註、交易時間
**用戶資料**
- Google 帳號 ID、使用者偏好設定

#### External API
是否需要API？
- **Google OAuth 2.0**：用戶登入驗證
- **Google Drive API**：資料同步與備份

#### Security / Privacy
- **登入安全**：使用 OAuth，避免儲存明文密碼
- **資料隱私**：課表與記帳資料為個人隱私，需確保只有本人可見
- **資料洩露風險**：若用第三方 API 備份，需簽署資料保護協議
- **本地存儲**：考慮在瀏覽器使用 IndexedDB 作為離線快取
- **HTTPS 強制**：所有通信必須加密
